GramChat

Instagram on Windows, Linux and Android — everything except Reels and Explore
● Reels & Explore hard-blocked Windows 10+ · Linux · Android 7+ WebView2 · WebKitGTK · Android WebView .NET 10 · Kotlin unofficial client

What it does

✅ The real Instagram

  • Home feed, profiles, follow / follow requests
  • Private accounts · notifications · settings
  • Teen accounts and parental supervision (Instagram's own controls)
  • Direct Messages with voice and video calls

🚫 Reels & Explore removed

  • No Reels rail tab, no in-feed reels, no profile Reels tab
  • No Explore page or explore-style recommendations
  • Blocked by path segment, so /someuser/reels/ is caught too
  • External links open in the system browser

🔒 Privacy

  • Password never seen or stored
  • Encrypted session database (SQLCipher AES-256)
  • Key protected by DPAPI / Keystore / 0600 file
  • "Log out & clear local data" wipes everything

How the guard works

LAYER 1 — NATIVE

Navigation guard

Services/NavigationPolicy.cs · webview/NavigationPolicy.kt — every top-level navigation and popup is classified as Allow / Bounce-to-Home / Block / Open-external. Reels and Explore are bounced back to the Home feed; links that leave Instagram open in your system browser.

LAYER 2 — IN-PAGE

SPA guard

Services/PageHardening.cs · webview/PageHardening.kt — Instagram's web client is a React SPA whose clicks never trigger real navigations. Injected JS hooks the History API, hides every Reels/Explore link and tab, and force-returns home if the router ever lands on one.

⚡ Event-driven, call-aware

One MutationObserver collapsed into a single animation frame (plus one 2 s backstop) replaces the old 250–500 ms polling loops. During a call all cosmetic DOM work pauses so the main thread stays free for WebRTC, and the shell keeps the screen awake (Android).

Run it

Windows

# from the repo root (local SDK: ../tools/dotnet-sdk)
dotnet publish src/GramChat/GramChat.csproj `
  -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true

Linux (.deb)

# from the repo root
./linux/build-deb.sh
sudo apt install ./dist/GramChat-1.0-Linux-beta1-amd64.deb

Android

# from android/
./build.sh
adb install android/app/build/outputs/apk/debug/app-debug.apk
